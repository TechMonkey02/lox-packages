# LOX Linux packages

The `[lox]` pacman repository for LOX Linux,
served by GitHub Pages at `https://techmonkey02.github.io/lox-packages/x86_64`.

LOX systems get it automatically from `lox-base`. Every package and both databases are signed
with the **LOX Linux Packages** key:

```
B4AC 08CA 0FE9 EC5C 08D5  BB89 3861 8448 89E8 0628
```

The public key is [`lox.gpg`](lox.gpg). Don't edit this repo by hand; it's written by `scripts/publish-repo.sh` in the LOX source repo.
